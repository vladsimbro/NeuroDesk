# NeuroDesk — справочник МКБ-10

Проект упрощён до двух экранов: главная страница и поисковый справочник МКБ-10.

## Что доступно

- Поиск по коду и русскому названию диагноза.
- Просмотр найденных рубрик.
- Просмотр иерархии кода: класс → блок → рубрика → подрубрика.
- Просмотр дочерних кодов и переход между ними.
- Каталог классов МКБ-10.
- Прямые ссылки на браузер МКБ-10 ВОЗ и официальный рубрикатор клинических рекомендаций Минздрава РФ.
- Адаптивная вёрстка для телефона и компьютера.

## Источник данных

Поисковый интерфейс обращается к открытому стороннему API XKT-10.VENA.UZ: https://xkt-10.vena.uz/api/

Это не официальный сервис Минздрава РФ. API заявляет поиск по русским и узбекским названиям; фактическая полнота и редакция его базы должны быть сверены с применимым российским нормативно-справочным ресурсом. Поэтому справочник предназначен для быстрой навигации, а не для автоматического выбора клинического диагноза или юридически значимого кодирования.

Официальные точки проверки:
- ВОЗ, браузер МКБ-10, версия 2019: https://icd.who.int/browse10/2019/en
- Рубрикатор клинических рекомендаций Минздрава РФ: https://cr.minzdrav.gov.ru/

## Запуск локально

Сайт статический. Для локального просмотра:

    python -m http.server 8000

Затем открой http://localhost:8000.

## Ограничения

Для работы поиска требуется интернет и доступность стороннего API. Если API недоступен, сайт покажет ошибку и оставит ссылки на первоисточники. Перед использованием кода в медицинской документации проверяй национальную редакцию, включения, исключения и правила кодирования.
