# NeuroDesk

NeuroDesk — компактный справочник российской МКБ-10.

## Что есть на сайте

- Главная страница с быстрым переходом к поиску.
- Отдельная вкладка «МКБ-10».
- Поиск по коду и названию диагноза через российский нормативно-справочный набор.
- Навигация по 22 классам классификации.
- Отображение кода, названия и родительской рубрики найденной записи.

## Источник данных

Используется российский нормативно-справочный набор МКБ-10 (OID 1.2.643.5.1.13.13.11.1005), опубликованный в каталоге DataCrafter. В опубликованном паспорте указано 15 038 записей и дата последнего обновления 25.10.2021. Набор описывает российскую адаптацию МКБ-10 и ссылается на письмо Минздрава РФ от 12.11.2020 № 13-2/753.

Источник и паспорт набора: https://data.apicrafter.ru/tables/nsimz/3720

Важно: дата выгрузки не подтверждает актуальность на текущий день. Перед кодированием диагноза в медицинской документации сверяй действующую редакцию классификатора и локальные нормативные требования. Сайт — навигационный справочник, не инструмент постановки диагноза.

## Технологии

Статический сайт на HTML, CSS и JavaScript. Поиск обращается к открытому API источника данных; для работы требуется подключение к интернету.

Локальный запуск: `python -m http.server 8000`, затем открыть http://localhost:8000.
