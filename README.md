# NeuroDesk

NeuroDesk — медицинский справочник с локальной российской МКБ-10, клиническими неврологическими статьями и шкалами/калькуляторами.

**Сайт:** https://vladsimbro.github.io/NeuroDesk/

## Разделы

- Главная: навигация и быстрые переходы.
- МКБ-10: российская база версии 2.27 (15 038 записей), 22 класса, интерактивное дерево рубрик и подрубрик, поиск по фрагментам названия/коду, фильтр класса, подсказки распространённых терминов и исправления опечаток. Доступны карточки с реальными родительскими связями, избранные и недавние коды, прямые ссылки и копирование.
- Клинический справочник: 31 расширенный неврологический обзор — осмотр, дифференциальная диагностика, красные флаги и наблюдение. Только российские источники: реестр 18 КР Минздрава, карточки с ID, годом, возрастом и границами применимости, поиск по текстам, чтение с вкладками.
- Шкалы и калькуляторы: 11 интерактивных инструментов — SCORE2/SCORE2-OP, GCS/GCS-P, mRS, ABCD², ICH Score, 4AT, RASS, NRS, MRC Sum Score, MAP и ИМТ.

## Работа со шкалами

Каждая шкала содержит критерии оценки, поля ввода, проверку ошибок, итоговый показатель, полную расшифровку клинического смысла, разбор составляющих баллов, ограничения и ссылки на источники. При изменении любого значения прежний результат сбрасывается. Отчёт с расшифровкой можно скопировать. Вводимые данные не отправляются на сервер.

Для mRS отдельно объясняются все категории 0–6: возможность выполнять привычные дела, ходить, обслуживать себя и потребность в посторонней помощи. GCS поддерживает отметку NT. Для SCORE2 автоматически выбирается модель по возрасту и региональная перекалибровка.

Подробнее: [Источники, методика и ограничения](docs/CALCULATORS.md).

## МКБ-10

Российская база версии 2.27 от 02.09.2024, OID 1.2.643.5.1.13.13.11.1005. Официальный паспорт: https://nsi.rosminzdrav.ru/dictionaries/1.2.643.5.1.13.13.11.1005/passport/2.27

Дата выпуска версии не подтверждает, что эта версия актуальна на сегодняшний день. Сверяй действующие правила кодирования перед применением.

## Запуск и тесты

Статический HTML/CSS/JavaScript на GitHub Pages, без собственного бэкенда. Локально запускается командой python3 -m http.server 8000, затем доступен по http://localhost:8000/ . Не открывай через file:// — ES-модулям нужен HTTP.

Для тестов Node.js 20+ и команда npm test. GitHub Actions дополнительно проверяет интерфейс в headless Chrome на настольной и мобильной ширине.

## Важно

NeuroDesk — справочный проект, а не зарегистрированное медицинское изделие. Технические тесты не являются медицинской валидацией. Нельзя автоматически переносить точность оригинальных опросников на адаптированные версии, а результаты — использовать для самостоятельного назначения или отказа от лечения.

**Эталонные проверки:** [матрица первоисточников, контрольных случаев и мобильных тестов](docs/CALCULATOR_VERIFICATION.md). На iPhone числовой результат, единицы измерения и название разделены на отдельные строки.

## МКБ-10: локальные функции и офлайн-доступ

При открытии раздела впервые через HTTPS браузер пробует подготовить автономную копию страниц и базы МКБ-10 через Service Worker `sw-icd.js`. Работоспособность без сети зависит от успешного сохранения кэша и политики конкретного браузера; другие разделы сайта специально не перехватываются. Поисковые фразы вроде «ишемический инсульт» дают **навигационные подсказки к рубрикам**, а не автоматическую постановку диагноза и не рекомендацию выбрать конкретный код.

Избранное и недавно открытые коды сохраняются только в `localStorage` этого браузера: сохраняются строки кодов МКБ-10 без персональных данных. При отключённом хранилище они доступны только в текущей сессии. В данном наборе отсутствуют все подробные «включено/исключено», алфавитный указатель и официальные правила кодирования — данные не дополнены непроверенными текстами. 

## Российские источники клинических статей

Тексты — оригинальные авторские русскоязычные конспекты, не копии КР и не замена официальному протоколу. Источники разделены на профильные и смежные по тематике и возрасту. Для тем без подтверждённой профильной КР выводится предупреждение. Дозировки и схемы лечения не добавлялись без независимой медицинской экспертизы. Подробнее: [источники и ограничения](docs/LITERATURE.md).

Длинные материалы подгружаются только при открытии клинического справочника, не нарушая автономную работу МКБ-10. Версия технического кэша обновлена для предотвращения выдачи старого общего JavaScript.
