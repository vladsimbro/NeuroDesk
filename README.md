# NeuroDesk

Цифровое рабочее пространство невролога с ориентацией на российскую медицинскую практику.

NeuroDesk объединяет клинические инструменты, навигацию по официальным источникам и интерактивные визуализации в одном адаптивном сайте.

## Текущий статус

Версия 0.1.0 — первая техническая основа проекта.

В текущей версии доступны:
- рабочая навигация по отдельным вкладкам;
- калькулятор GCS / ШКГ с отдельными компонентами E, V и M;
- обработка NT: итоговая сумма не показывается, если хотя бы один компонент не поддаётся оценке;
- автоматические тесты расчёта;
- ссылки на российские официальные медицинские ресурсы;
- демонстрационная 3D-сцена;
- реестр медицинского качества.

Важно: GCS реализована технически и покрыта автоматическими тестами, но до клинического применения необходима независимая проверка практикующим специалистом. Текущая 3D-модель — визуальный прототип, а не проверенный анатомический атлас.

## Запуск локально

Сайт статический, серверная часть и база данных для текущей версии не нужны.

    python -m http.server 8000

Открой http://localhost:8000.

Для тестов нужен Node.js 20 или новее:

    npm test

## Медицинское качество

Смотри:
- [Политику медицинского качества](docs/MEDICAL_QUALITY.md)
- [План развития](docs/ROADMAP.md)

NeuroDesk не ставит диагноз, не назначает лечение и не заменяет клинические рекомендации или профессиональное медицинское решение. Непроверенные инструменты не публикуются как готовые.

## Архитектура

- index.html — точка входа;
- assets/css/ — интерфейс и темы;
- assets/js/calculators.js — расчётная логика;
- assets/js/app.js — навигация и страницы;
- assets/js/brain-scene.js — демонстрационная 3D-сцена;
- assets/js/resources.js — каталог шкал и официальных источников;
- tests/ — автоматические проверки;
- docs/ — медицинская политика и roadmap.

## Приватность

В текущей версии данные пациентов не запрашиваются и не сохраняются. Не вводи идентифицирующую информацию пациентов в сайт. Функции хранения пациентских данных требуют отдельного проектирования и правовой оценки.
