# NeuroDesk — матрица верификации калькуляторов

Дата сверки: 10 ноября 2026 года. Версия: отдельный модуль \`calculators.html\`.

**Что проверено:** математическая или категориальная реализация каждой из 11 интерактивных карточек сверена с опубликованным описанием, а для SCORE2/SCORE2-OP — с авторскими уравнениями и коэффициентами. В репозитории есть исполняемые контрольные случаи и браузерные тесты. **Не проверено:** эквивалентность конкретной версии оригинального закрытого приложения HeartScore, независимая клиническая валидация, медизделие/регистрация, диагностические характеристики русской адаптации 4AT, тестирование в настоящем Safari на устройстве пользователя.

## Проверка SCORE2/SCORE2-OP

- [tests/reference-comparison.test.mjs](../tests/reference-comparison.test.mjs) содержит **18 фиксированных численных контрольных профилей**: возраст, пол, курение, давление, холестерин, ЛПВП, регион и ожидаемый процент с точностью до 10 десятичных знаков.
- Ожидаемые числа вычислены **отдельной реализацией уравнений**, переписанных с оригинального Stata-кода авторов. В CI сравниваются с реализацией NeuroDesk с допуском 0,000001 процентного пункта. Это уменьшает риск опечатки или изменения коэффициентов, но **не является исполнением оригинального Stata-файла или сертификацией сторонним правообладателем**.
- Например: SCORE2, мужчина 60 лет, без курения, САД 120, общий холестерин 6, ЛПВП 1,3, умеренный регион → **6,3237736551%**.
- SCORE2-OP, мужчина 75 лет, курит, САД 150, общий холестерин 5,9, ЛПВП 1,4, низкий регион → **20,3094217524%**. Очень высокий регион для того же профиля → **41,4190435278%**.
- В одной сторонней [онлайн-публикации примеров](https://magentlab.com/docs/score2-op) для похожего профиля указаны иные значения; приоритет отдаётся опубликованной исходной формуле авторов, в которой присутствует вычитание \`lp_mean\`. Наличие такого расхождения означает, что **нельзя обещать совпадение со всеми сторонними калькуляторами**.

## Мобильный интерфейс

- Результат структурирован семантически: подпись / число / единица / название / значение / отдельный перечень факторов / клинические ограничения.
- Для небольших экранов единица измерения и длинное название никогда не занимают одну строку с числом.
- Обновлены CSS/JS-ресурсы для сброса старого мобильного кэша.
- [tests/browser-smoke.html](../tests/browser-smoke.html) с headless Chromium проверяет расположение элементов, отсутствие горизонтального переполнения и взаимных перекрытий на ширинах **320, 375, 390 и 414 px**.
- Отдельный тест на реальном Safari/iOS остаётся желательным: Chromium не эмулирует все особенности рендеринга WebKit.

## Границы завершённости

Состояние: **функционально реализовано и технически сверено с методиками в перечисленных сценариях**. Это **не** разрешение для профессионального медицинского применения, не независимая экспертиза алгоритмов и не гарантия идентичности всякому оригинальному интерфейсу и версии. У адаптированной 4AT нельзя предполагать чувствительность/специфичность исходного варианта без отдельной валидации.
