# Что сейчас есть в NeuroDesk

Проект намеренно сокращён до справочника МКБ-10.

## Главная страница
- Оставлена отдельная главная страница с переходом в справочник.
- Удалена навигация по прежним демонстрационным разделам.

## Вкладка «МКБ-10»
- Поиск по коду и русскому названию.
- Выдача до 100 совпадений на запрос.
- Открытие карточки кода с иерархией.
- Просмотр вложенных уточняющих подрубрик.
- Просмотр 22 классов/основных разделов, если их возвращает API.
- Счётчик кодов и классов запрашивается у API и отображается по его ответу.
- Добавлены прямые ссылки на ВОЗ и Минздрав РФ.

## Важное ограничение
Поиск использует сторонний открытый API, а не официальный сервис Минздрава РФ. До подтверждения полноты и актуальности национального набора данных его нельзя считать единственным источником для кодирования. Если API недоступен, поиск не работает; ссылки на официальные ресурсы остаются доступны.
