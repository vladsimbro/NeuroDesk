# Качество и ограничения справочника МКБ-10

## Назначение
NeuroDesk — поисковый интерфейс для навигации по российской МКБ-10. Он не ставит диагноз, не подбирает код автоматически по симптомам и не заменяет клиническое решение.

## Источник данных
Локальная база соответствует российскому справочнику OID `1.2.643.5.1.13.13.11.1005`, версия **2.27 от 02.09.2024**. Паспорт Минздрава указывает 15 038 записей, ответственную организацию — Министерство здравоохранения РФ, уполномоченную — ФГБУ «ЦНИИОИЗ» Минздрава России.

Исходная выгрузка: https://github.com/ak4nv/mkb10/blob/master/resources/1.2.643.5.1.13.13.11.1005_2.27.csv. Сохранены все поля исходного набора: ID, REC_CODE, MKB_CODE, MKB_NAME, ID_PARENT, ADDL_CODE, ACTUAL, DATE.

## Проверки при импорте
- 15 038 строк и 15 038 уникальных ID.
- Все заполненные ID_PARENT ссылаются на существующие записи.
- Контрольные записи A00, A00.0, A00.1, F00, F00.0, G43 и U07.1 присутствуют.
- Сохранены 101 запись с ACTUAL=0 и дополнительные коды ADDL_CODE=1 (+) / 2 (*).

## Ограничение актуальности
Версия 2.27 опубликована 02.09.2024. Это последняя подтверждённая российская версия, найденная при подготовке этой сборки; отметки сторонних сайтов о проверке в 2026 году не означают существование версии 2.28. Паспорт указывает срок подтверждения актуальности до 30.09.2027. Перед использованием кода в медицинской документации сверяй действующую редакцию, включения/исключения и правила кодирования.

## Технические ограничения
- JSON загружается при открытии вкладки МКБ-10; внешний API поиска не используется.
- По умолчанию скрыты записи с ACTUAL=0; их можно включить переключателем.
- Дополнительные коды + и * отображаются как атрибуты записи; их применение требует проверки правил двойного кодирования.
- Браузер ВОЗ 2019 может отличаться от российской национальной адаптации.
