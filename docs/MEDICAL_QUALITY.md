# Качество и ограничения справочника МКБ-10

## Назначение
NeuroDesk — поисковый интерфейс для навигации по российской МКБ-10. Он не ставит диагноз, не подбирает код автоматически по симптомам и не заменяет клиническое решение.

## Источник данных
Локальная база соответствует российскому справочнику OID `1.2.643.5.1.13.13.11.1005`, версия **2.27 от 02.09.2024**. Паспорт Минздрава указывает 15 038 записей, ответственную организацию — Министерство здравоохранения РФ, уполномоченную — ФГБУ «ЦНИИОИЗ» Минздрава России.

Исходная выгрузка: https://github.com/ak4nv/mkb10/blob/master/resources/1.2.643.5.1.13.13.11.1005_2.27.csv. Сохранены все поля исходного набора: ID, REC_CODE, MKB_CODE, MKB_NAME, ID_PARENT, ADDL_CODE, ACTUAL, DATE.

## Проверки при импорте
- 15 038 строк и 15 038 уникальных ID.
- Все заполненные ID_PARENT ссылаются на существующие записи.
- Контрольные записи A00, A00.0, A00.1, F00, F00.0, G43 и U07.1 присутствуют.
- Сохранены 101 запись с ACTUAL=0 и дополнительные коды ADDL_CODE=1 (+) / 2 (*).

## Ограничение актуальности
Версия 2.27 опубликована 02.09.2024. Это последняя подтверждённая российская версия, найденная при подготовке этой сборки; отметки сторонних сайтов о проверке в 2026 году не означают существование версии 2.28. Паспорт указывает срок подтверждения актуальности до 30.09.2027. Перед использованием кода в медицинской документации сверяй действующую редакцию, включения/исключения и правила кодирования.

## Новая навигация МКБ-10
- Классы XX, XXI, XXII отображаются в соответствии с официальной последовательностью: V01–Y98, Z00–Z99, U00–U85.
- Подрубрики и родители отображаются исключительно по связям `ID_PARENT` исходной базы. Соседние коды — записи общего родителя, а не медицинские эквиваленты.
- Карточка показывает только реально загруженные поля: код, название, статус, дату и признаки дополнительного кодирования. **Полные примечания «включено» / «исключено», алфавитный указатель и правила кодирования в этой выгрузке отсутствуют**; пользователь должен сверять официальный источник.
- Адрес `?code=G43.1#icd` открывает конкретную запись версии 2.27, не подбирает диагноз по симптомам.

## Дополнительные пользовательские функции
- Дерево строится по реальным ID_PARENT; раскрытие узла не означает, что его потомок допустим для автоматического назначения в диагнозе.
- Подсказки для общеупотребительных названий (например, «ишемический инсульт») ведут к широкой рубрике, а не к конкретной четвёртой категории. Сопоставления составлены вручную как навигационные ориентиры и **не являются частью исходной базы НСИ**.
- Предложение исправить опечатку — только предложение: исходный поисковый запрос без нажатия пользователя не заменяется.
- Избранное и недавние коды хранятся как строки кодов в `localStorage`, без ФИО, анамнеза или иных данных пациентов. Локальное хранилище может быть очищено браузером.
- `sw-icd.js` сохраняет только ресурсы раздела МКБ-10 и главную страницу, не перехватывает страницы клинического справочника и калькуляторов. Офлайн-работа после успешной первоначальной загрузки не гарантирована при запрете Service Worker/Cache Storage или очистке кэша.
- Для подробных включений/исключений открывай официальный источник и действующую редакцию кодирования; публикация ВОЗ 2019 может отличаться от российской адаптации.

## Технические ограничения
- JSON загружается при открытии вкладки МКБ-10; внешний API поиска не используется.
- По умолчанию скрыты записи с ACTUAL=0; их можно включить переключателем.
- Дополнительные коды + и * отображаются как атрибуты записи; их применение требует проверки правил двойного кодирования.
- Браузер ВОЗ 2019 может отличаться от российской национальной адаптации.
