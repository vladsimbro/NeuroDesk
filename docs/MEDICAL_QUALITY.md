# Качество и ограничения справочника МКБ-10

## Назначение
NeuroDesk в текущей версии — поисковый интерфейс для навигации по МКБ-10. Он не ставит диагноз и не выбирает код автоматически на основании симптомов.

## Источник данных
Поисковые результаты, карточки кодов и иерархия загружаются из стороннего API XKT-10.VENA.UZ. Это не официальный сервис Минздрава России. Сторонний источник может отличаться по редакции, составу кодов, терминологии и правилам национальной адаптации.

## Проверка перед использованием
Перед внесением кода в медицинскую документацию необходимо сверить:
- применимую редакцию российской нормативно-справочной версии;
- включения и исключения;
- правила применения дополнительных знаков и уточняющих подрубрик;
- требования конкретной медицинской информационной системы и действующих нормативных документов.

Официальные ресурсы:
- ВОЗ: https://icd.who.int/browse10/2019/en
- Минздрав РФ: https://cr.minzdrav.gov.ru/

## Технические ограничения
Для поиска нужен интернет. При недоступности API сайт показывает сообщение об ошибке; локальной полной копии базы в проекте нет. API и его полнота не проходят независимую медицинскую/нормативную валидацию в рамках этого проекта.
