# NeuroDesk — план и состояние

## Реализовано

- [x] Единая главная страница, светлый дизайн и навигация.
- [x] Российская локальная МКБ-10 версии 2.27: 15 038 записей, короткий поиск, фильтры и проверка исходных данных.
- [x] Все 22 корректно пронумерованных класса, карточки записей, реальная иерархия, связанные рубрики, прямые ссылки и копирование кодов.
- [x] Дерево рубрик/подрубрик с раскрытием по ID_PARENT; поиск внутри класса без сброса фильтра.
- [x] Навигационные поисковые соответствия и предложения исправления опечаток без автоматического назначения кодов.
- [x] Избранное и недавние коды только в локальном хранилище; ограниченный офлайн-доступ через Service Worker.
- [x] Расширенные тесты на исходной базе и проверки браузерных сценариев.
- [x] Клиническая библиотека: 31 статья, поиск, категории, окно чтения и вкладки.
- [x] Все 31 статьи расширены индивидуальными разделами по обследованию, дифференциальной диагностике, срочным симптомам и наблюдению.
- [x] Российский реестр 18 КР, профильное/смежное отношение к каждой статье, возрастные границы и предупреждения об отсутствии прямого источника.
- [x] Расширенный полнотекстовый поиск и отложенная загрузка медицинских материалов, независимая от МКБ.
- [x] 11 шкал/калькуляторов с реальными расчётами.
- [x] SCORE2/SCORE2-OP: возрастная модель, коэффициенты и европейские регионы риска.
- [x] GCS/GCS-P, mRS, ABCD², ICH Score, 4AT, RASS, NRS, MRC Sum Score, MAP, BMI.
- [x] Полная расшифровка всех результатов и компонентов, объяснение степеней mRS 0–6.
- [x] Отметки NT для GCS и зрачков без подмены баллов.
- [x] Подсказки и клинические ограничения для каждого инструмента.
- [x] Проверки ввода, отмена устаревшего результата, копирование отчёта.
- [x] Автоматизированные тесты и браузерные проверки Chrome.

## Возможные будущие задачи

- [ ] Независимая предметная экспертиза всех 31 статей с проверкой клинически значимых утверждений по пунктам актуальных российских КР.
- [ ] Повторная проверка статусов и прямых ссылок всех 18 КР; добавление проверенных лечебных протоколов только после экспертного рецензирования.
- [ ] Тестирование чтения длинных материалов на настоящем Safari/iOS.
- [ ] Независимая клиническая валидация и экспертиза для профессионального использования.
- [ ] Правовая и методическая проверка новых шкал (NIHSS, MoCA и др.) перед добавлением.
- [ ] Проверка обновлений официальной МКБ-10 и загрузка следующих версий.

Техническое прохождение тестов не является медицинской сертификацией.
