# NeuroDesk — план развития

## Текущая задача
Поддерживать компактный и быстрый справочник российской МКБ-10.

## Реализовано
- [x] Главная страница с быстрым переходом к классификатору.
- [x] Отдельная вкладка «МКБ-10».
- [x] Поиск по коду и названию диагноза через открытый API российского нормативно-справочного набора.
- [x] Навигация по 22 классам МКБ-10.
- [x] Показ кода, наименования, родительской записи и признака неактуальности, если он передан источником.
- [x] Удалены из пользовательской навигации прежние демонстрационные разделы: калькуляторы, 3D-анатомия, фармакология, диагностика и контроль качества.
